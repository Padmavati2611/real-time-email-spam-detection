# 📧 Real-Time Email Spam Detection

## 📌 Project Overview
Real-Time Email Spam Detection is a machine learning project designed to identify whether an email is **Spam** or **Not Spam (Ham)**. The system analyzes email text and predicts whether the message is unwanted or legitimate.

## 🎯 Objectives
- Detect spam emails automatically.
- Apply machine learning techniques to text classification.
- Improve email security by identifying unwanted messages.
- Learn practical applications of Python and machine learning.

## 🛠️ Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- NumPy

## ⚙️ How It Works
1. Collect and prepare email text data.
2. Clean and preprocess the text.
3. Convert text into numerical features.
4. Train a machine learning classification model.
5. Predict whether an email is spam or legitimate.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Padmavati2611/real-time-email-spam-detection.git
   ```

2. Open the project folder:

   ```bash
   cd real-time-email-spam-detection
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy scikit-learn
   ```

4. Run the main Python file:

   ```bash
   python app.py
   ```

   Replace `app.py` with the actual Python filename if your project uses a different entry point.

## 📊 Expected Output
The system classifies an email into one of two categories:

- **Spam:** An unwanted or suspicious email.
- **Not Spam (Ham):** A legitimate email.
